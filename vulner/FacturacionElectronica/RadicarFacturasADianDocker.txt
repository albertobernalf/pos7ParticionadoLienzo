Paso 1: Requisitos Previos en la DIAN
Habilitación: Registrarse como facturador electrónico y realizar el SET de pruebas (2 facturas, 1 nota crédito, 1 nota débito).
Credenciales: Obtener el NIT, SoftwareID y Pin del software de facturación.
Certificado Digital: Contar con el archivo .p12 o .pfx para firmar el XML.

Paso 3: Crear el Dockerfile
Cree un archivo llamado Dockerfile en la misma carpeta que app.py.
dockerfile
# Usa una imagen oficial de Python
FROM python:3.9-slim

# Establecer directorio de trabajo
WORKDIR /app

# Copiar archivos necesarios
COPY requirements.txt .
COPY app.py .
COPY factura.xml .

# Instalar dependencias (zeep para SOAP)
RUN pip install --no-cache-dir requests zeep

# Ejecutar la aplicación
CMD ["python", "app.py"]
